# Plataforma de Cursos Online

Proyecto de la Evaluacion 1 de Backend con Python y Django.

## Descripcion

Base de una plataforma de cursos online. Por ahora el proyecto cuenta con:

- Ambiente virtual de Python
- Proyecto Django (motor_django)
- Aplicacion cursos con su pagina de bienvenida
- Pagina personalizada de error 404

## Como ejecutar el proyecto

1. Crear el ambiente virtual:

```
python -m venv .venv
```

2. Activar el ambiente virtual:

```
.venv\Scripts\Activate
```

3. Instalar las dependencias:

```
pip install -r requirements.txt
```

4. Ejecutar el servidor:

```
python manage.py runserver
```

5. Abrir en el navegador http://127.0.0.1:8000
